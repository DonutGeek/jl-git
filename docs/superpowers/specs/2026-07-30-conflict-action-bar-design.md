# 冲突文件操作栏布局设计

日期：2026-07-30

## 目标

冲突文件预览不再让整文件操作按钮与文件路径共用一行，避免长路径被压缩，并明确区分文件定位、整文件冲突操作和预览工具。

## 布局

冲突文件显示三行：

1. 路径行：冲突标识、文件图标、可复制路径。
2. 冲突操作行：左侧显示“检测到合并冲突，可逐块处理或选择整文件版本”，右侧显示“采用本地 / 采用远程 / 标记已解决”。
3. 现有预览工具栏：编码、文件视图/差异视图、冲突导航及布局操作。

非冲突文件仍保持现有两行结构，不显示冲突操作行。编辑器内部逐块采用当前、采用传入、保留双方的操作保持不变。

## 交互与样式

- 操作行使用紧凑高度、底部分隔线和标准水平间距。
- 左侧提示允许截断，右侧按钮不收缩。
- 三个按钮的顺序、禁用状态和现有处理逻辑不变。
- 操作行提供冲突区域的可访问名称。
- 提示文案进入 `repo` 中英文资源。

## 验收

- 冲突文件路径行不再包含整文件操作按钮。
- 新操作行位于路径行与预览工具栏之间。
- 长路径、长分支名下布局不重叠。
- 忙碌状态仍会禁用三个整文件操作按钮。
- 非冲突预览及编辑器内逐块操作无变化。
- `pnpm check` 与 `pnpm build` 通过。
