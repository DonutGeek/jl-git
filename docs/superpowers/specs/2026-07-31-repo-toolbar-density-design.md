# 仓库工具栏密度自适应设计

日期：2026-07-31

## 目标

工具栏按**自身容器宽度**收缩，窄窗时少占横向空间，避免右侧工具与同步区互相挤压。

## 已确认规则

| 项 | 规则 |
|----|------|
| 触发 | 工具栏根节点 `ResizeObserver`（非窗口媒体查询） |
| 收紧顺序 | **先**右侧四工具进 `⋯`，**再**缩左侧（优先级：工具 < 仓库名/分支/视图文案） |
| 藏文案 | 主视图 + 同步只留图标；仓库名 / 分支名缩窄 truncate（仍露字）；角标保留 |
| `⋯` 内容 | 仅右侧四工具：外部编辑器、分支比较、文件管理器、终端 |
| 始终平铺 | 同步三键（及发布分支） |
| 防抖 | 档位切换带 hysteresis，避免临界宽度来回跳 |

## 档位

| 档位 | 条件（初值，实现可微调） | UI |
|------|--------------------------|-----|
| `comfortable` | 默认 / 宽 | 图标+文案；右侧四工具平铺 |
| `compact` | 宽 `< 1120` | 文案仍完整；右侧四工具进 `⋯` |
| `minimal` | 宽 `< 960` | 再缩左侧（仅图标 + 窄仓库名/分支）；`⋯` 保留 |

说明：阈值须高于窗口 `minWidth`（900）。工具栏与窗同宽，旧值 900/720 在可缩放范围内几乎永不触发。

## 非目标

- 同步区收进 `⋯`
- 主视图收进 `⋯`
- 通用全局 `useMediaQuery` 封装（首期仅工具栏）

## 实现要点

1. 纯函数 `resolveRepoToolbarDensity(width, previous)` + 常量阈值
2. `RepoToolbar` 根节点挂 ref + `ResizeObserver`
3. `⋯` 用现有 `DropdownMenu`；菜单项图标+文案

## 自检

- 无占位 / TODO
- 与「先工具、后左侧」优先级一致
- 范围仅 `RepoToolbar` + 小工具函数 + i18n
