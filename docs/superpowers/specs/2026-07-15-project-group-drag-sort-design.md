# 项目分组拖拽排序设计

## 目标

在「分组」视图中支持同级分组排序、分组内项目排序，以及把项目拖入其他分组。所有顺序与项目归属写入 SQLite，重启应用后保持不变。

## 范围

- 根分组与同一父分组下的子分组可拖拽排序；不支持通过拖拽改变分组层级。
- 项目可在同一分组内排序，也可拖到另一分组或“无分组”根节点；拖放后更新 `workspaceId` 与排序值。
- 分组视图内的项目行不再显示本地路径；分组行和项目行采用统一单行高度。
- 复用已有 `@dnd-kit`，不新增依赖。

## 数据模型与持久化

- `projects` 表增加 `sort_order INTEGER NOT NULL DEFAULT 0`，项目列表在同一 `workspace_id` 内按 `sort_order`、名称排序。
- 新增批量排序 Command：接收有序的分组 ID 列表及有序项目项（项目 ID、目标 `workspaceId`、排序位置），在单个 SQLite 事务内写入。
- 所有输入 ID 在事务中验证存在；不匹配的项目/分组返回领域错误，不进行部分写入。
- 前端仅在 Command 成功后确认最终顺序；失败时恢复拖放前顺序并显示 toast。

## 交互

- 拖动手势在整行生效；点击仍选中，双击与 Enter 仍打开项目。
- 拖动中的原行半透明，使用轻量 `DragOverlay` 显示当前行；目标位置显示间隙指示。
- 分组仅能在拥有相同 `parentId` 的区域内排序。
- 项目可投放到项目之间，或投放到任一展开分组的空位；根“无分组”区域作为合法投放目标。
- 拖拽期间禁止项目打开、创建分组和其他排序操作，防止竞态。

## 布局与视觉

- 分组行与项目行统一为紧凑单行高度（约 36px）。
- 分组内项目仅显示图标与名称；路径保留在最近列表，避免分组树纵向膨胀。
- 继续使用现有 Design Tokens、悬停和焦点样式；拖拽反馈不改变布局占位宽度。

## 测试与验收

- Rust 测试覆盖：项目排序字段迁移、批量排序事务、跨分组移动、非法 ID 回滚。
- 前端纯函数测试覆盖：拖放结果到批量请求的映射与非法分组目标过滤。
- 验收：根分组与子分组排序、同组项目排序、项目跨组/移至无分组、重启持久化、拖拽取消、双击打开均正常；Light/Dark 无错位或白屏。

## 非目标

- 不支持分组拖到另一个分组中改变父级。
- 不支持一次拖拽多个项目。
- 不添加分组路径、收藏或远端地址相关能力。
