# 设置 · 性能面板

> 日期：2026-07-22  
> 状态：已实现  
> 前置：关于页已有运行状态可视化

## 目标

- **关于**仅展示品牌 / 版本 / 环境 / 更新
- 设置左侧新增 **性能**（位于关于上方）
- 本应用进程指标仪表盘：环形图 + sparkline + 进度条（方案 1）
- 颜色走 Design Tokens，不抄 Codex 配色

## 指标

| 指标 | 来源 | 可视化 |
|------|------|--------|
| CPU% | `system_runtime_stats`（扩展） | 环 + sparkline |
| RSS | 同上 | 环 + sparkline |
| 运行时长 / PID | 同上 | 大数字卡片 |
| 线程数 | 同上（可选，取不到则隐藏） | 卡片数字 |
| 打开标签 / 窗口 | 前端 store + Tauri webviews | MeterBar |
| 应用数据目录体积 | 新 command `app_data_usage`（低频） | 卡片 + 可选环 |

## 行为

- 仅在性能页打开时轮询：运行时 ~1s；数据目录 ~10s
- Windows CPU 仍可能为 0 → 显示「—」
- 不做主机级监控、不做 Git/Agent 业务耗时

## 不做

- 主机 CPU/内存总览
- 导出性能报告
- 独立悬浮窗
