# Git 身份头像默认回退图标设计

## 目标

当 Git 身份未检测到公开头像，或头像加载失败时，统一显示默认用户图标，不再显示用户名称缩写，避免小尺寸圆形头像中的文字拥挤。

## 方案

- 保持 `GitIdentityAvatar` 作为唯一的头像展示组件。
- 邮箱可生成且成功加载 Libravatar 时，继续展示远程头像。
- 未提供邮箱、服务端无头像或图片加载失败时，`AvatarFallback` 统一展示 lucide `User` 图标。
- 保留现有身份名称 Tooltip、`aria-label` 与组件尺寸控制。

## 影响范围

共享组件改动将同步应用于状态栏、提交区和提交历史中的 Git 身份头像；不改变 Git 身份读取、网络请求或状态管理。

## 验证

- 运行 `pnpm exec tsc --noEmit`。
- 在开发环境打开仓库，确认状态栏与提交区在无公开头像时显示默认用户图标；头像可用时仍显示图片。
