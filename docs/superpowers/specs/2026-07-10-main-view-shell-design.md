# 主视图骨架（工作区 / 变更 / 历史）— 设计

> 日期：2026-07-10  
> 范围：**布局骨架优先（方案 A + 实现路径 1）**  
> 相关截图：用户提供的工作区文件浏览器、变更左右分栏、历史左右分栏

## 目标

点击工具栏「工作区 / 变更 / 历史」时，**侧栏右侧整块主区**切换为对应布局，对齐参考截图的信息架构；本轮不做真 Diff / 读文件内容 / 历史图 / 提交详情 API。

## 不变

- 顶栏仓库标签、`RepoToolbar`、活动栏、侧栏（目录树 / 分支）保留
- 软切换仓库、无整页拆壳

## 主区结构

| `mainView` | 结构 |
|------------|------|
| `workspace` | 单栏：面包屑（仓库名 > 相对路径）+ 网格/列表切换 + 当前目录条目（`fs_list_dir`）；双击/点目录进入；点文件仅选中（无预览） |
| `changes` | 左右分栏：左 = `ChangesPanel` + `CommitBox`；右 = 空状态「选择文件查看 Diff（即将支持）」 |
| `history` | 左右分栏：左 = `HistoryList`；右 = 空状态「选择提交查看详情（即将支持）」 |

## 非目标（本轮）

- `git_diff` / `git_show` / 读文件内容
- 历史分支图、提交正文、改动文件列表
- 变更区点文件打开 Diff

## 验收

- 三视图切换无白屏、无 Maximum update depth
- 工作区可浏览目录（网格默认）
- 变更/历史左右分栏可见，右侧为明确占位文案
- `tsc` 通过；文案走 i18n
