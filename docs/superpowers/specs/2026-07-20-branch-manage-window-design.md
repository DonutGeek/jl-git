# 分支管理子窗设计

## 背景

侧栏分支树适合切换与右键操作；需要一张可筛选、可看 tip 元数据的管理视图。「活跃」按 tip 提交新鲜度判断（非仅当前检出）。

## 决策

| 项 | 选择 |
|----|------|
| 承载 | 独立 Tauri Webview 子窗（对齐文件历史 / 分支比较） |
| 活跃 | tip `authoredAt` 距今 ≤ **90 天** |
| 数据 | 扩展 `git_branches` / `for-each-ref`，增加 tip shortId / 时间 / 作者 |
| 范围 | 列表 + 筛选 + 复制；本地非当前分支可删除（确认框可选同步删远端）；合并仍走侧栏 |

## UI

- 顶栏：标题「分支管理」
- 工具行：本地 | 远端；全部 / 活跃 / 不活跃（计数）；刷新；关键字
- 紧凑表：分支（当前 ✓、默认标）、跟踪、最新提交、时间（默认可降序切换）、作者、状态、操作（复制 / 删除）

## 非目标（首期）

- 批量删除、合并、改名、仅删远端跟踪分支
- 可配置活跃天数（常量即可）
- 照搬参考应用的大留白宽表
