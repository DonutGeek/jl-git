# 全量 Lucide 图标选择器设计

日期：2026-07-30

## 目标

仓库图标与分组图标统一使用同一个图标选择器。选择器列出当前 `lucide-react` 提供的全部图标，支持搜索与页码分页，并保持离线可用、主包轻量与交互流畅。

## 参考行为

参考 Vben Pro IconPicker：

- 图标名称列表进入选择器后先搜索过滤，再分页展示。
- 每页默认展示 30 个图标（6×5），单元格为正方形圆角。
- 搜索关键词或结果总数变化时自动回到第一页。
- 搜索无结果时显示明确空状态。
- 底部分页为图标按钮：上一页 / 页码 / 下一页（无首页/末页，无 Previous/Next 英文文案）；首页附近展示 `1 2 3 4 5 … N`。

JLGit 不采用 Vben 的 Iconify 在线获取模式，继续只使用 `lucide-react`，避免网络依赖和第二套 UI 图标体系。

## 架构

### 图标注册表

- 从 Lucide 官方动态导入表获取完整 kebab-case 图标名称。
- 注册表提供排序后的名称列表、名称合法性判断和单个图标异步解析。
- 动态加载结果按名称缓存。
- 禁止通过 `import * as icons from "lucide-react"` 静态引入全部图标。

### 动态图标

- 提供共享动态图标渲染组件。
- 只加载实际出现在当前页或业务界面中的已选图标。
- 加载中使用固定尺寸占位，不造成网格布局跳动。
- 无效或历史未知名称回退到领域默认图标。

### 共享选择器

- 业务层统一使用 `LucideIconPicker`（组合 Shadcn `Popover`、`Command`、`Pagination`、`Tooltip`）。
- 仓库 / 分组等场景禁止另起图标选择器；领域文案通过 `lucideIconPickerI18n` 注入。
- `WorkspaceGroupDialog` 使用共享选择器。
- 不修改 `src/components/ui/**`。

## 交互

- Popover 中依次显示搜索框、图标网格和分页区。
- 每页 30 个图标，桌面布局为 6×5；单元格 `aspect-square` + `rounded-md`。
- 搜索约 200ms 防抖，匹配 Lucide 原始名称及格式化展示名。
- 关键词或结果总数变化时页码重置为第一页。
- 分页区提供上一页、页码（含省略）、下一页；首页附近为 `1…5 … N`；首尾页正确禁用。
- 选择图标后立即回填并关闭 Popover。
- 当前图标具有选中状态；每个纯图标按钮提供 `aria-label` 和 Tooltip。
- 支持键盘进入搜索框与 Esc 关闭。

## 数据与兼容

- 项目和分组图标字段统一保存 Lucide kebab-case 名称。
- 现有 20 个项目图标和 5 个分组图标继续有效，无需迁移。
- TypeScript 在数据边界进行运行时校验，不使用巨型手写联合类型。
- Rust 校验图标字符串长度与 kebab-case 格式，拒绝空值和异常输入。
- 读取到未知旧值时前端使用默认图标显示，但不导致页面崩溃。

## 性能

- 主界面只加载实际使用的图标组件。
- 选择器打开后仅渲染当前页 30 个 SVG，不创建全量图标 DOM。
- 名称搜索在字符串数组上执行，`Command` 关闭重复的内部全量过滤。
- 动态组件和搜索结果使用模块级缓存；分页切换不重复加载已访问图标。

## 文案

- 搜索占位、无结果、分页 aria/Tooltip 走 i18n。
- 全量图标不维护约 2000 条翻译；展示名由 kebab-case 转为可读标题。
- 现有常用图标翻译可继续作为展示名覆盖。

## 验收

- 仓库和分组选择器都可浏览全部 Lucide 图标。
- 默认每页 30 个（6×5），底部分页为图标 + 页码样式。
- 搜索后自动回到第一页；无匹配结果时不报错。
- 选择结果可保存、重启恢复并在所有现有展示位置正确渲染。
- 打开选择器不会一次性渲染或静态打包全部图标组件。
- Light/Dark、焦点、Tooltip 与 Popover 关闭行为正常。
- `pnpm check`、`pnpm build` 通过，并完成仓库与分组选择器运行时冒烟。
