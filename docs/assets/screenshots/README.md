# 截图资源

将产品截图放在本目录，供 [README](../../README.md) 引用。

| 建议文件名 | 内容 | 建议尺寸 |
|------------|------|----------|
| `dashboard.png` | 仪表盘 | 1600×1000，Light 主题 |
| `repository.png` | 仓库 Status / Commit | 同上 |
| `diff.png` | Diff 视图 | 同上 |

要求：

- 使用真实 UI，不使用造假数据冒充完成功能以外的能力
- 避免出现私人路径、邮箱、token
- 优先 Light 主题；可选附加 `*-dark.png`
